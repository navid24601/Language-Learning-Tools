# Vocabulary analysis

Start with the sense intended in context. If ambiguity matters, ask or show the most relevant alternatives. Select only useful features: part of speech, meaning, grammatical pattern, collocation, register, connotation, related forms or a near-synonym contrast. Use examples that make the sense clear; do not imply every combination works in every sense.

*Economic* concerns an economy or economics (“economic growth”); *economical* can mean saving money or resources (“an economical car”). “She is resilience” uses a noun where an adjective is needed: “She is resilient.” “She has resilience” uses the noun.

Acknowledge uncertainty or variation and consult a suitable dictionary or corpus when available; do not invent usage or frequency claims.
