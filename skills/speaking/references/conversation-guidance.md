# Conversation and feedback

Set a plausible role, situation and communication goal. If the user has not specified them, choose a simple opening instead of asking several setup questions. Follow the learner’s response, keep turns manageable and let them steer. If they struggle, rephrase, offer a choice or model a useful response.

Agree on feedback timing if it matters; otherwise use a light touch. When feedback is wanted, target consequential points and distinguish an error from a valid but less typical expression. Resume the interaction. Text does not demonstrate pronunciation, accent or listening performance.
