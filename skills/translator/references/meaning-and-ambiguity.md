# Meaning and ambiguity

Use when a faithful translation requires a choice beyond word substitution.

- **Ambiguous source:** English *bank* can refer to a financial institution or a river edge. Ask for context when the distinction changes the translation; if useful, give labeled alternatives.
- **Negation and uncertainty:** “She might not come” expresses possibility of non-attendance, not certainty that she will not come. Preserve both uncertainty and negation.
- **Idiom:** “It’s raining cats and dogs” means very heavy rain. A natural target-language equivalent or plain paraphrase usually conveys the intended meaning better than translating each animal literally; label a literal version if requested.
- **Register:** A formal request and a casual message can need different phrasing. Use the audience and instructions supplied, and avoid adding politeness, gender, agency or facts the source does not require.

If a target language forces a distinction absent from the source, ask when consequential or give alternatives. State uncertainty when you cannot reliably judge a language or nuance.
