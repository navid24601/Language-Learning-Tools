# Explaining grammar

Connect the relevant form to its meaning and situation. Give a natural example and a contrasting example when it changes the choice; avoid presenting a tendency as an absolute rule. For instance, “I lived there for five years” can describe a completed period, whereas “I have lived there for five years” normally implies that I still live there.

Ask for context when the intended meaning matters. Distinguish a grammatical error from a register, style or regional choice. Select terminology the learner can use, and mention exceptions only when relevant.
