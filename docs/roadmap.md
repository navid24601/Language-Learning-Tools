# Roadmap

## Five-skill release candidate

Five independent skills, concise references, a portable skills-only manifest, and manual evaluation cases are implemented. Structural checks cover package files and cases. Vocabulary version 0.1.0 was discovered in this Codex session; version 0.2.1 installation and five-skill behavior remain unverified.

## Validate and refine

Refresh the local marketplace copy and install 0.2.1. In fresh Codex sessions run the cases in `evals/`, including implicit discovery, explicit invocation, negative routing and multi-turn feedback; record host, model, version, prompts, outputs and judgments. Fix observed failures and re-run affected and regression cases. Ask learners and teachers for feedback and, if useful, examine delayed retrieval. These checks do not prove learning gains. Test ChatGPT separately before claiming support.

## Distribution

Verify a clean install, updates, all references and five-skill routing. Document supported hosts and limitations; only then consider a release. Publishing requires a separate decision.

## Future, subject to need

Consider opt-in profiles, progress, spaced review, integrations and MCP only after establishing user needs and a privacy, consent, export and deletion design. None is required for this version.
