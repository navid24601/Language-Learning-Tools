# Vocabulary evaluation protocol

Manual suite: `cases.json`. Structural validation only checks dataset shape; it does not run the agent. Use a fresh session per case. For activation tests, enable the plugin/skill but do not explicitly invoke it; observe whether the host actually selects the skill, if selection is visible. Mark unobservable selection “unknown,” not pass. For behavior tests explicitly invoke the skill and follow the turns in order, without showing the evaluator checks to the agent. Record actual outputs, host, model, date, package revision, invocation, references accessible, each check and rubric score, critical failures and notes. Repeat selected cases without the skill as a baseline when practical. Do not assume matching answer wording is required. For multi-turn cases send the next prescribed user turn after the response; evaluate each checkpoint. A learner's correction may be valid even if phrased differently.

Grade using `rubric.md`. Separate activation from response quality. Re-run failed cases and a representative regression set after changes. A template is in `results-template.md`; do not invent results. The suite is a development sample, not proof of learning gains.
